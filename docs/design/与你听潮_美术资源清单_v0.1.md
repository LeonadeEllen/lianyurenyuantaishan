## 10. 产能估算（参考）

| 工种 | MVP 阶段人数 | 首发阶段人数 |
|---|---|---|
| 原画（角色/场景/卡牌插画） | 6–8 | 20–30（含外包） |
| 3D 角色 | 4–6 | 12–16 |
| 3D 场景 | 4–6 | 12–16 |
| 动画（含动捕整理） | 4–6 | 12–20 |
| 特效 | 2–3 | 6–8 |
| UI/UX | 2–3 | 6–8 |
| 技术美术 | 2–3 | 4–6 |

> 卡牌插画、配角、通用 NPC、部分场景可外包；男主模型、表情、共鸣技与剧情演出建议核心团队自研，保证品质一致。

## 11. 美术制作的先后顺序

1. **第 1 个月**：风格定义（氛围图 + 沈砚舟设定图 + UI 风格），确定品质标杆
2. **第 2–3 个月**：沈砚舟完整 3D 品质标杆（模型 + 表情 + 栖所 + 1 段剧情演出），作为全项目品质参考
3. **第 3–6 个月**：陆曜、MVP 关卡、蚀影、卡牌、战斗特效，完成垂直切片
4. **切片评审通过后**：闻溪、季夙与首发全量资源并行生产
