# 《与你听潮》玩法框架 v0.1

> 配套文档：《与你听潮_策划案_v0.2》（世界观与男主设定见该文档）
> 本文档定义系统结构、核心循环、各系统规则与解锁节奏，供策划、程序、美术拆分需求使用。
> 数值均为**框架性初值**，以垂直切片测试结果为准。

## 1. 系统总览

```
                    ┌────────────── 主城：澜城（大地图/据点） ──────────────┐
                    │                                                        │
   【恋爱侧】        │        【战斗侧】                 【养成侧】           │
   心语（手机）      │        主线关卡                   回响卡（卡牌）       │
   栖所（3D陪伴）    │        资源副本                   心核盘（搭配）       │
   约会（3D剧情）    │        周常Boss                   男主等级/天赋        │
   潮汐日历          │        深潮（爬塔）               调律天赋树（女主）   │
   好感/羁绊         │        活动关卡                   抽卡/商店            │
                    └────────────────────────────────────────────────────────┘
                           ↑ 剧情系统贯穿：主线 / 个人线 / 卡牌记忆 / 活动剧情
```

| 系统 | 产出 | 消耗 | 解锁条件 |
|---|---|---|---|

| 资源副本 | 卡牌经验、突破材料、金币 | 体力 | 主线 1-5 |
| 心语 | 好感、少量钻石 | 无 | 初始 |
| 栖所 | 好感、心情值 | 栖所行动点 | 主线 1-3 |

| 心核盘 | 套装效果 | 无（镶嵌） | 主线 2-1 |
| 周常 Boss | 高级突破材料 | 挑战次数 | 主线 3-10 |
| 深潮（爬塔） | 钻石、心核盘饰品 | 无 | 主线 4-10 |

## 2. 核心循环

### 2.1 日循环（目标 15–25 分钟）
1. 登录 → 收到男主早安消息/来电（情感钩子）
2. 进入栖所，与当日"潮汐心情"不同的男主互动（3–5 分钟）
3. 清体力：资源副本扫荡 + 推一两关主线（8–12 分钟）
4. 日常任务结算 → 钻石/抽卡券
5. 晚间：晚安来电、动态圈更新（召回钩子）

### 2.2 周循环
- 周常 Boss（3 次）、深潮重置、每周约会 1 次（大剧情）、周任务宝箱

### 2.3 版本循环（6 周）
- 第 1 周：新主线章节 + 限定卡池 A 上线
- 第 3 周：主题活动（活动关 + 活动剧情 + 兑换商店）
- 第 5 周：限定卡池 B / 复刻池 + 小活动
- 第 6 周：版本预告、直播

## 3. 恋爱侧

### 3.1 心语（手机模拟）
| 模块 | 规则 |
|---|---|
| 消息 | 每位男主每日 1–3 条主动消息，按时间段触发；每条 2–3 个回复选项，选择影响好感（+1~+3）与后续话题 |
| 来电 | 早安/晚安固定来电；特殊来电由好感等级、节日、生日、潮汐事件触发；全语音，可收藏回放 |
| 动态圈 | 男主每日发 0–1 条动态，玩家可评论；其他男主可能留言，制造群像感 |
| 话题库 | 消息按"日常/工作/情绪/暧昧"四类话题池抽取，好感越高暧昧话题权重越大 |

### 3.2 栖所（3D 陪伴空间）
- **行动点**：每日 5 点，每次互动消耗 1 点
- **互动类型**
  - 闲聊：随机话题 + 实时表情反馈
  - 共事：小游戏化（陆曜：修车拧螺丝节奏点击；闻溪：古籍修复拼图；沈砚舟：整理卷宗分类；季夙：品茶/下棋）
  - 触碰：点击男主不同部位的反应（遵循平台尺度）
  - 赠礼：赠送礼物，按男主喜好加成好感
- **心情值**：0–100，受潮汐日历与互动影响；心情高时解锁特殊对话，心情低时可触发"安慰"事件（高好感奖励）
- **家具**：栖所可装扮，家具来源为活动、商店、约会纪念物

### 3.3 潮汐日历（差异化核心）
- 每日自动生成当日潮汐：**小潮 / 中潮 / 大潮 / 静潮夜**（静潮夜每周 1 次）
- 影响：
  - 每位男主有对应的"潮汐体质"（如闻溪大潮时情绪低落、陆曜大潮夜会去赛车）
  - 决定当日可约会地点池
  - 静潮夜：全员可能触发特殊剧情事件（随机 1 位），提升"想每天上线看看"的动机
- 日历提前 7 天公开，玩家可规划

### 3.4 约会
- 消耗约会券（每周发放 2 张，活动可得）
- 流程：选男主 → 选地点（受潮汐影响）→ 3D 剧情 + 1 个小互动（拍照/选礼物/选路线）→ 结算纪念物与好感
- 每个地点 × 每位男主 = 独立剧情，按好感分 3 档差分

### 3.5 好感与羁绊
| 好感等级 | 解锁 |
|---|---|
| Lv.1–3 | 基础消息、栖所闲聊 |
| Lv.4–6 | 约会、来电称呼变化、个人线 1–4 章 |
| Lv.7–9 | 暧昧话题、栖所特殊互动、个人线 5–8 章 |
| Lv.10+ | 专属语音包、隐藏剧情、个人线后续章节 |

## 4. 战斗侧

### 4.1 基础结构
- 女主 + 1 位男主组队（男主即本次出战卡牌所属男主）
- 女主由玩家操作；男主 AI 辅助，**共鸣技释放时切换为电影镜头**
- 单关 2–4 分钟；三星评价（通关 / 未倒地 / 限时）

### 4.2 操作（移动端）
| 按键 | 功能 |
|---|---|
| 摇杆 | 移动 |
| 普攻 | 4 段连击 |
| 闪避 | 无敌帧闪避，有体力条限制 |
| 格挡 | 按住格挡，正确时机触发"回潮" |
| 技能 ×2 | 由出战卡牌提供，冷却制 |
| 男主协攻 | 命令男主释放其专属技（冷却制） |
| 共鸣技 | 共鸣值满时可用 |

### 4.3 潮汐节奏机制
- 敌人的重攻击前出现**潮音提示**（地面波纹 + 音效），分为 3 种：
  - 蓝潮：可格挡
  - 白潮：可闪避，不可格挡
  - 红潮：必须打断（男主协攻可打断）
- 在判定窗口（初值 0.25 秒）内正确应对 → **回潮**：子弹时间 1 秒 + 女主反击 + 共鸣值 +20
- 普攻、技能命中也会缓慢积累共鸣值
- 共鸣值满（100）→ 释放**双人共鸣技**：全屏演出 + 高额伤害；SSR 卡牌有专属共鸣技演出

### 4.4 男主战斗定位
| 男主 | 定位 | 协攻技 | 被动 |
|---|---|---|---|
| 沈砚舟 | 控制 | 锁链束缚，打断红潮 | 被控敌人受伤增加 |
| 陆曜 | 爆发 | 冲刺连击 | 回潮后男主攻速提升 |
| 闻溪 | 辅助 | 潮灯护盾 + 回血 | 女主倒地时可救起一次 |
| 季夙 | 破防 | 剑舞破甲 | 回潮后对敌附加破防 |

### 4.5 敌人设计
- **蚀影小怪**：3 类基础（近战 / 远程 / 自爆），每章新增 1 种变体
- **精英蚀影**：带 1–2 种潮音机制
- **Boss**：每章 1 个，多阶段，阶段转换带演出；周常 Boss 有更复杂的潮音组合

### 4.6 关卡类型
| 类型 | 说明 |
|---|---|
| 主线关卡 | 每章 10–15 关，含剧情关（短剧情 + 战斗）与 Boss 关 |
| 资源副本 | 经验 / 金币 / 突破材料三类，可扫荡 |
| 周常 Boss | 每周 3 次，难度分级，产出高级材料 |
| 深潮（爬塔） | 50 层，每月重置，有特殊环境词条（如"潮音加速"） |
| 活动关 | 版本活动专属，含机制玩法 |

## 5. 养成侧

### 5.1 回响卡
| 稀有度 | 来源 | 内容 |
|---|---|---|
| R | 常驻池、商店 | 插画 + 短剧情（1 段） |
| SR | 卡池、活动 | 插画 + 动态卡面 + 剧情（2 段）+ 专属语音 |
| SSR | 卡池 | 3D 动态卡面 + 剧情（3 段）+ 专属语音 + 专属共鸣技演出 + 觉醒卡面 |

- 每张卡带一种**情绪属性**：喜 / 哀 / 怒 / 惧 / 念
- 卡牌提供：攻击、生命、防御 + 1 个主动技能 + 1 个被动

### 5.2 卡牌养成
| 养成项 | 规则 |
|---|---|
| 升级 | 消耗经验道具，等级上限受突破限制 |
| 突破 | 每 20 级一次，共 4 次，消耗突破材料 |
| 觉醒 | 突破满后解锁，消耗高级材料，获得觉醒卡面 + 第 3 段剧情 |
| 星级 | 消耗重复卡，1–5 星，提升技能等级 |

### 5.3 心核盘
- 每位男主一个六角网格，初始 3 格，随男主等级扩展到 7 格
- 出战卡牌必须镶嵌在该男主心核盘上，中心格为"主卡"（决定共鸣技演出）
- **情绪连线**：相邻卡牌情绪属性相同或相生（喜→念→哀→惧→怒→喜）时形成连线
  - 2 连：小加成（如攻击 +5%）
  - 3 连：中加成 + 特殊效果（如回潮判定窗口 +0.05 秒）
  - 5 色齐全：解锁"心潮满溢"，共鸣技伤害大幅提升
- 设计意图：让 R/SR 卡也有搭配价值，降低纯数值追 SSR 的压力

### 5.4 记忆组（卡牌即叙事）
- 每位男主有若干"记忆组"，每组 3–5 张卡（混合 R/SR/SSR）
- 集齐一组 → 解锁一段"大退潮之夜"隐藏剧情 + 心核盘饰品
- 记忆组中至少 1 张为非限定卡，保证零氪可推进核心悬念

### 5.5 男主等级与女主天赋
- **男主等级**：消耗男主专属材料，提升基础属性与心核盘格数
- **调律天赋树**（女主）：3 系（攻击 / 防御 / 共鸣），使用主线进度奖励的天赋点

### 5.6 抽卡
| 卡池 | 规则（初值，需合规公示） |
|---|---|
| 常驻池 | SSR 1.5%，SR 10%，70 抽硬保底 SSR |
| 男主限定池 | SSR 1.5%，出 SSR 时 50% 为当期限定；未中则下次 SSR 必为限定（大保底） |
| 生日池 | 生日限定卡，保底规则同限定池 |
| 回响商店 | 限定卡下池 3 个版本后，可用"回响币"（抽卡返还）兑换 |

## 6. 解锁节奏（新手期）

| 时间点 | 解锁内容 | 设计目的 |
|---|---|---|
| 0–10 分钟 | 序章：女主觉醒 + 首战（沈砚舟救场 → 女主第一次回潮） | 战斗爽感 + 男主初印象 |
| 10–20 分钟 | 心语、四位男主依次登场 | 让玩家看完所有人再"站队" |
| 20–30 分钟 | 首次抽卡（新手池，必出 SSR 自选） | 情感投资起点 |
| 第 1 天 | 栖所、资源副本、心核盘 | 建立日循环 |
| 第 2–3 天 | 约会、潮汐日历、个人线 | 留存钩子 |
| 第 7 天 | 周常 Boss、第一个记忆组可集齐 | 中期目标 |
| 第 14 天 | 深潮爬塔、天赋树全开 | 长期目标 |

## 7. 经济框架（初值）

| 资源 | 产出 | 消耗 |
|---|---|---|
| 体力 | 每 6 分钟 1 点，上限 120 | 关卡 |
| 金币 | 副本、日常 | 升级、突破 |
| 钻石（免费） | 主线、日常、活动、深潮 | 抽卡、补体力 |
| 钻石（付费） | 充值 | 抽卡、外观、礼包 |
| 回响币 | 抽卡返还 | 回响商店 |
| 约会券 | 每周 2 张、活动 | 约会 |
| 行动点 | 每日 5 点 | 栖所 |

- 免费玩家月度可获抽数目标：约 60–80 抽（保证每版本约 1 张限定 SSR 的期望）
- 月卡玩家：约 100–120 抽

## 8. 剧情系统结构

| 类型 | 体量（首发） | 呈现 |
|---|---|---|
| 主线 | 6 章，每章约 1.5 万字 | 3D 实时演出 + 战斗 |
| 个人线 | 每人 8 章 | 3D 演出为主 |
| 卡牌剧情 | 每张卡 1–3 段 | 2D 插画 + 3D 动态 |
| 约会剧情 | 每人 × 地点 × 3 档 | 3D 演出 |
| 活动剧情 | 每版本 1 篇 | 3D/2D 混合 |

## 9. MVP 验证目标

| 验证项 | 指标 |
|---|---|
| 战斗手感 | 测试玩家"回潮"成功率 30–60%，战斗满意度 ≥ 4/5 |
| 陪伴感 | 栖所平均停留 ≥ 3 分钟/日 |
| 男主吸引力 | 两位男主好感选择分布不极端（各 ≥ 30%） |
| 留存 | 内测次留 ≥ 50%，7 日留存 ≥ 25% |
| 卡牌叙事 | ≥ 60% 玩家主动查看卡牌剧情 |
