# 《与你听潮》游戏策划案 v0.2

> 英文名：*Hear the Tide with You*
> Slogan：**「潮水会带走记忆，但带不走我想见你。」**
> 品类：3D 女性向恋爱 + 动作战斗 + 卡牌养成（移动端，兼顾 PC）
> 定位：对标《恋与深空》的品类体验与品质量级，在题材、男主、核心系统上做差异化
> 文档状态：概念立项稿，供内部评审

---

## 0. 命名

### 0.1 推荐：《与你听潮》
- "与你"直接点出"你和他"的二人关系，是乙女向命名里最有代入感的写法
- "听潮"对应世界观（静潮、调律师能"听见"心声），既浪漫又有画面感
- 四个字，好记，适合做图标字与应用商店搜索词

### 0.2 备选
| 名字 | 感觉 |
|---|---|
| 《潮汐恋人》 | 直白，一眼就知道是恋爱游戏 |
| 《恋雾之城》 | 偏悬疑浪漫，突出雾港氛围 |
| 《心潮予你》 | 更温柔、偏文艺 |
| 《未完的潮汐》 | 偏剧情向，留悬念 |

> 注意避开"恋与 X"的句式：它是叠纸旗下两款产品共用的命名风格，用户会直接联想成"山寨"，商标检索也容易撞车。正式立项前需做商标查重。

## 0.5 对标与差异化

### 对标什么（品类共识，可以学）
《恋与深空》验证了一套已被市场接受的体验结构，这些属于品类通用做法，本案保留：
- 第一人称代入的女主，3D 男主实时演出，陪伴感强
- 男主不只是谈恋爱的对象，还是并肩战斗的搭档（"恋爱 + 动作战斗"）
- 卡牌承载男主的高光演出，是付费核心
- 手机消息/来电、生日月、节日限定等长线情感运营节奏
- 全语音、高品质角色渲染，强调"他真的存在"的临场感

### 哪里不一样（必须差异化）
| 维度 | 对标产品 | 本案 |
|---|---|---|
| 题材 | 宇宙、深空、科幻猎人 | 近未来海港、记忆与潮汐，潮湿温柔带悬疑 |
| 女主定位 | 战斗者 / 被选中的人 | 调律师，能"听见"男主的心声，主动去修补他 |
| 男主职业 | （不参考具体人设） | 上司检察官 / 地下赛车手 / 灯塔守夜人 / 财阀继承人 |
| 战斗核心 | 以动作操作为主 | 踩"潮汐节奏"格挡反击 + 双人共鸣合击，强调配合 |
| 卡牌意义 | 演出与数值 | **卡牌即叙事**：集齐记忆组拼出男主隐藏过去 |
| 养成结构 | 卡牌搭配 | 六角"心核盘"，用情绪属性连线组成搭配 |
| 互动玩法 | 3D 互动 | **潮汐日历**：每天潮汐不同，影响约会地点与男主心情 |
| 美术基调 | 冷色太空科幻 | 雾感写实，深海蓝 + 灯塔暖黄 |

### 红线（不能碰）
不使用对标产品的名称、男主人设与外形、剧情桥段、UI 布局、美术资产与配乐；宣发不出现"某某平替"之类的话术。

## 0.9 差异化三支柱
- **题材**：放弃宇宙/科幻主轴，改用"海洋 + 记忆"的近未来港城题材，氛围更潮湿、温柔、带悬疑感。
- **战斗**：以"潮汐节奏"为核心的格挡反击 + 双人共鸣，强调"和他一起打"的配合感，而不只是"他来救我"。
- **养成**：卡牌不只是数值，而是"记忆碎片"，卡牌收集直接拼出男主的隐藏过去（卡牌即叙事）。

## 1. 核心概念

**一句话**：在被雾与潮汐吞没记忆的港城，你是唯一能"听见"他人心声的调律师——而他们，都曾在某次潮汐里失去过一部分自己。

**体验关键词**：陪伴感 · 被看见 · 并肩作战 · 解开他的秘密

**目标用户**：18–30 岁女性玩家，核心为乙女/女性向手游用户，次核心为喜欢动作手游、重视剧情与角色的玩家。

---

## 2. 世界观

### 2.1 舞台：澜城
近未来（约 2070 年）的海滨超级城市，由旧城、填海新区与海上浮岛三层构成。城市常年被一种特殊海雾"静潮"笼罩。

### 2.2 核心设定
- **静潮**：二十年前一次未解释的"大退潮"后出现的现象。每次涨潮时，人们的部分记忆与情绪会被海雾带走。
- **心核**：强烈情感会在人体内凝结为看不见的"心核"。心核越完整，人越不受静潮影响。
- **蚀影**：被静潮带走的情绪在海中聚合成形，于雾夜登岸，侵蚀人类心核。它们是战斗的主要敌人。
- **调律师**：极少数能与他人心核"共鸣"的人，可修补心核、驱散蚀影。女主（玩家）是新觉醒的调律师。

### 2.3 势力
| 势力 | 定位 |
|---|---|
| 澜城海事署·第七科 | 官方处理蚀影事件的部门，女主入职的地方 |
| 汐语会 | 民间互助组织，收留失忆者，立场暧昧 |
| 深蓝重工 | 掌控填海与浮岛的巨型企业，似乎在研究静潮 |
| 灯塔守夜人 | 传说中的古老守护者，几乎无人见过 |

### 2.4 主线悬念
女主自己就是"大退潮"的幸存者，却完全不记得那一夜。四位男主都与那一夜有关，而女主的调律能力，可能正是静潮的源头之一。

## 3. 男主角色（4 位）

设计原则：四人覆盖"冷 / 热 / 温 / 危"四种情感张力，职业、武器、战斗定位互不重叠，且每人有一个与主线相连的秘密。

### 3.1 沈砚舟 —— 克制的守护
- **身份**：海事署第七科科长，女主的上司，28 岁
- **性格**：理性、寡言、规矩至上，私下极度护短；不擅长表达，会用"工作安排"掩饰关心
- **外形关键词**：深灰制服、银边眼镜、左手常戴黑手套
- **战斗定位**：近战控制 / 武器为可伸缩锁链刃，擅长束缚与打断
- **秘密**：他的左手早已被蚀影侵蚀，靠意志压制。他接近女主，起初是为了找到治愈自己的方法
- **情感弧线**：利用 → 动摇 → 坦白 → "就算治不好，我也想留在你身边"

### 3.2 陆曜 —— 炽热的自由
- **身份**：旧城地下赛车手兼机修师，24 岁
- **性格**：张扬、嘴硬心软、讲义气，嘴上叫女主"小古板"，其实最先注意到她的情绪
- **外形关键词**：机油味夹克、耳钉、手臂旧伤疤
- **战斗定位**：高机动爆发 / 武器为机械拳套，带位移冲刺
- **秘密**：他是"大退潮"那夜被女主救下的孩子，一直在找她，却不敢相认，因为那夜之后她失去了记忆
- **情感弧线**：玩笑 → 守护 → 相认的挣扎 → "这次换我来记住你"

### 3.3 闻溪 —— 温柔的谜
- **身份**：浮岛古籍修复师，自称 26 岁，实际年龄不明
- **性格**：温和、慢节奏、说话像念诗，偶尔流露出与年龄不符的苍凉
- **外形关键词**：浅色长发、旧式长衫与现代大衣混搭、随身提灯
- **战斗定位**：远程辅助 / 武器为潮灯，可治疗、减速、制造护盾
- **秘密**：他就是传说中的"灯塔守夜人"，已守护澜城上百年，每次静潮都会失去一部分自己的记忆
- **情感弧线**：旁观 → 好奇 → 害怕再次遗忘 → "如果我又忘了你，请再来找我一次"

### 3.4 季夙 —— 危险的诱惑
- **身份**：深蓝重工继承人，表面是慈善家，27 岁
- **性格**：优雅、游刃有余、喜欢试探，道德灰色地带，对女主有近乎偏执的兴趣
- **外形关键词**：白西装、蓝宝石袖扣、笑意不达眼底
- **战斗定位**：中距离技巧 / 武器为细剑，招式华丽、带破防与反击
- **秘密**：深蓝重工正在人为制造静潮，而他一直在暗中破坏父亲的计划，代价是被双方都视为敌人
- **情感弧线**：利用 → 对峙 → 背叛家族 → "整座城都可以不要，你不行"

### 3.5 女主
- 不设固定外貌（捏脸系统），设定性格底色为"温柔但有主见"
- 剧情选项提供 2–3 种回应倾向（坦率 / 克制 / 俏皮），影响对话差分与好感事件，不影响主线走向

## 4. 核心循环

```
日常登录 → 亲密互动（短时、高情感回报）
       ↘ 战斗关卡/日常副本（获取养成资源）
       ↘ 抽卡/养成（提升战力 + 解锁卡牌剧情）
       → 战力提升 → 推进主线/个人线 → 解锁新互动内容 → 回到日常
```

- **短循环（每日 15–20 分钟）**：消息/来电 → 栖所互动 → 日常副本 → 体力清空
- **中循环（每周）**：周常 Boss、约会剧情、限时活动关卡
- **长循环（每版本 6 周）**：新主线章节、新卡池、男主个人线新篇

## 5. 恋爱与互动系统

### 5.1 心语（手机模拟）
- **消息**：男主会根据时间、天气、玩家行为主动发消息；分支回复影响好感
- **来电**：语音通话（全语音），含早安/晚安/节日特殊来电
- **动态圈**：男主的社交动态，可评论，其他男主偶尔会互动（制造群像感）

### 5.2 栖所（3D 陪伴空间）
- 每位男主有专属的 3D 居所（沈砚舟的办公室公寓、陆曜的车库、闻溪的灯塔书房、季夙的海上别墅）
- 玩家可进入陪伴：聊天、一起做事（修车、修书、泡茶等小互动），实时表情与动作反馈
- 互动以"日常陪伴"为核心，尺度遵守平台与版号规范

### 5.3 约会
- 3D 全演出约会剧情，每月更新；含可选地点与少量小游戏
- **独创点：潮汐日历**——澜城每天潮汐不同，影响可约会的地点和男主心情（例如大潮夜闻溪会情绪低落，此时陪伴可触发特殊剧情）

### 5.4 好感与羁绊
- 好感等级解锁：称呼变化、专属语音、栖所新家具、个人线章节
- 个人线：每位男主 12 章起步，随版本更新

## 6. 战斗系统

### 6.1 基本形态
- 3D 实时动作，女主 + 一位男主同场作战（女主可操作，男主 AI 辅助；关键时刻切换为男主操作）
- 单局 2–4 分钟，适配移动端

### 6.2 核心机制：潮汐节奏
- 敌人的强攻击带有"潮音"提示（视觉波纹 + 音效）
- 在潮音节拍上格挡/闪避，可触发 **"回潮"**：短暂时停 + 反击
- 连续回潮累积 **共鸣值**，满值后释放 **"双人共鸣技"**：女主与男主合击的电影级演出（每张高稀有卡附带专属共鸣技演出）

### 6.3 男主差异
| 男主 | 战斗风格 | 共鸣技示例 |
|---|---|---|
| 沈砚舟 | 控制、打断 | 锁链束缚全场，女主完成终结 |
| 陆曜 | 位移、爆发 | 背靠背连击冲刺 |
| 闻溪 | 治疗、护盾 | 潮灯照亮海面，两人在光中合击 |
| 季夙 | 破防、反击 | 双人剑舞 |

### 6.4 关卡类型
主线关卡 · 资源副本 · 周常 Boss · 爬塔（"深潮"） · 限时活动关 · 后期开放的高难挑战

## 7. 卡牌与养成系统

### 7.1 回响卡（记忆卡牌）
- 每张卡 = 女主与某位男主的一段记忆（插画 + 3D 动态演出 + 卡面剧情）
- 稀有度：R / SR / SSR（暂定三档）
- 卡牌提供：战斗属性、主动技能、共鸣技演出（SSR）
- **卡牌即叙事**：同一男主的部分卡牌属于同一"记忆组"，集齐一组可解锁该男主"大退潮之夜"的隐藏记忆片段

### 7.2 心核盘（独创养成）
- 每位男主拥有一个六角网格的"心核盘"，卡牌镶嵌其中
- 相邻卡牌的"情绪属性"（喜 / 哀 / 怒 / 惧 / 念）形成连线，触发套装效果
- 既有搭配深度，又让不同卡牌组合"讲述"不同的情绪故事

### 7.3 养成线
卡牌等级 → 突破 → 觉醒（解锁觉醒卡面）→ 星级（重复卡获取） ； 男主个人等级 ； 女主调律天赋树

### 7.4 抽卡
- 常驻池 + 男主限定池 + 节日/生日限定池
- 保底：SSR 硬保底 + 限定池"大保底"（具体概率按国内规范公示，例如 SSR 基础概率 1%–2%）
- **防过度消费设计**：限定卡在一定周期后进入"回响商店"可用活动代币兑换，降低错过焦虑

## 8. 商业化

| 付费点 | 说明 | 占比预估 |
|---|---|---|
| 卡池抽取 | 主要收入，限定男主卡、生日卡 | 60–70% |
| 月卡 | 每日小额钻石 + 专属来电 | 10% |
| 战令 | 每版本一期，含专属卡面与装扮 | 8–10% |
| 外观 | 男主服装、栖所家具、女主服装 | 8–12% |
| 礼包 | 新手/成长礼包，限购 | 5% |

原则：
- 战力不过度依赖付费，非付费玩家可以通关全部主线
- 男主核心剧情不付费锁死，付费主要购买"更多与他相关的记忆与演出"
- 严格遵守未成年人防沉迷与概率公示要求

## 9. 长线运营

- **版本节奏**：6 周一个大版本，含新主线章节 + 一位男主限定池 + 主题活动
- **固定节点**：四位男主生日（重点营收节点，每人一个"生日月"活动）、情人节、七夕、白色情人节、周年庆
- **社区运营**：男主官方社交账号（以角色身份发布动态）、配音演员互动、同人创作激励
- **新角色规划**：首年稳定四人，第二年视数据加入第五位男主（需保证剧情合理性，避免稀释现有男主）
- **数据监控**：次日/7 日/30 日留存、各男主好感分布、卡池转化率、栖所互动时长

## 10. 技术与美术方向

### 10.1 引擎与技术
- **引擎**：Unity（URP，移动端成熟度高、人才多）或 UE5（画质上限高、移动端优化成本大）。**建议 Unity URP + 自研角色渲染管线**，在中端机上保证 30fps、高端机 60fps
- **角色渲染**：高精度角色模型 + 次表面散射皮肤 + 发丝渲染 + 实时布料
- **表演**：面部捕捉 + 动作捕捉驱动的剧情演出；对话场景使用实时 3D 而非预渲染视频
- **语音**：全剧情中文配音，后续考虑日语配音
- **平台**：iOS / Android 首发，PC 端同步

### 10.2 美术风格
- **整体风格**："雾感写实"——偏写实的人物比例，配合低饱和、潮湿、带柔光的海港氛围
- **色彩基调**：深海蓝、雾灰、灯塔暖黄作为主色，每位男主有专属强调色（沈砚舟铁灰、陆曜橙红、闻溪月白、季夙宝石蓝）
- **场景**：旧城的老骑楼与霓虹、填海新区的玻璃高楼、浮岛的悬空花园与灯塔
- **蚀影设计**：半透明、水母与雾气结合的形态，避免恐怖血腥，偏"哀伤的美"

## 11. MVP 范围与里程碑

### 11.1 MVP（垂直切片）范围
- 2 位男主（建议沈砚舟 + 陆曜，覆盖"冷/热"两极，验证情感张力差异）
- 主线第 1–2 章 + 每人个人线前 3 章
- 战斗：核心潮汐节奏机制 + 1 个双人共鸣技 + 3 个关卡 + 1 个 Boss
- 栖所：每人 1 个空间，5 种互动
- 心语：消息与来电基础功能
- 卡牌：每人 6 张卡（含 1 张 SSR），心核盘基础功能，抽卡流程
- 目的：验证"3D 陪伴感 + 战斗爽感 + 卡牌叙事"三者结合是否成立

### 11.2 里程碑（参考，需按团队规模校准）
| 阶段 | 时长 | 产出 |
|---|---|---|
| 概念期 | 2 个月 | 世界观与角色定稿、美术风格探索、战斗原型（灰盒） |
| 垂直切片 | 6 个月 | 上述 MVP，可进行小规模内部测试 |
| 制作期 | 10–12 个月 | 4 位男主、主线前 6 章、完整养成与商业化 |
| 测试期 | 4–6 个月 | 2–3 轮封闭测试、版号申请（与制作期并行准备） |
